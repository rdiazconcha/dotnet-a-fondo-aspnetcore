# .NET a fondo: ASP.NET Core

## Curso de LinkedIn Learning en español

Aprende a desarrollar aplicaciones y servicios web con ASP.NET Core y amplía tus conocimientos del ecosistema .NET. En este curso descubrirás los fundamentos de esta plataforma, sus principales componentes y los diferentes tipos de proyectos que permite crear. Conocerás las herramientas y los recursos necesarios para construir soluciones web y comprenderás cómo se integran sus elementos en una aplicación real. A través de un proyecto práctico para la empresa ficticia FabuRobotics, aprenderás a desarrollar una aplicación web con API y a aplicar los conceptos esenciales de ASP.NET Core en un entorno de desarrollo.
